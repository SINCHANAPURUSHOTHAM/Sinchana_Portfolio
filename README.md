### 2. 📄 **DocuQuery — RAG-Based Document Q&A Chatbot**
- **Tech Stack**: `Python` · `LangChain` · `ChromaDB` / `FAISS` · `Claude API` · `Streamlit`
- **Description**: Ingests PDFs and notes, chunks and embeds vectors for semantic search, and integrates the Claude API for grounded, context-aware Q&A over private documents.

### 3. 🌐 **SkillBridge — AI Skill Gap Analyzer & Career Platform**
- **Tech Stack**: `React` · `Python Flask` · `Claude API` · `Docker` · `Kubernetes`
- **Description**: Parses resumes with NLP to generate match scores against role databases, orchestrating personalized learning roadmaps with radar visualizations.

- **Tech Stack**: `Python` · `Signal Processing` · `Broadband Stitching` · `ML Forecasting`

### 5. 📊 **GradeX — University Grading System**
- **Tech Stack**: `MongoDB` · `Express` · `React` · `Node.js` · `Selenium`
- **Description**: Role-based university assessment platform featuring automated grade calculation APIs and end-to-end UI regression testing using Selenium.

### 6. 🔍 **AI-Powered SEO Content Optimizer**
- **Tech Stack**: `BeautifulSoup` · `scikit-learn` · `LangChain` · `Claude API` · `Streamlit`
- **Description**: Scrapes and scores web content for SEO performance, delivering real-time LLM-driven content enhancements in an interactive Streamlit app.

### 7. 🛰️ **Satellite Tracker Android App**

## 💻 Local Setup & Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/SINCHANAPURUSHOTHAM/Sinchana_Portfolio.git
   cd Sinchana_Portfolio/SINCHANA_PORTFOLIO
   ```

2. **Run Locally**:
   - Open `index.html` directly in any web browser, OR
   - Launch via Python HTTP server:
     ```bash
     python -m http.server 8000
     ```
   - Open `http://localhost:8000` in your browser.
